## 🎯 **Como Usar a Nova Estrutura**

### **Desenvolver**
```bash
# Aplicação principal
cd app/                    # Backend FastAPI
cd nextjs_dashboard/       # Frontend Next.js

# Banco de dados
cd alembic/               # Migrações
alembic upgrade head      # Aplicar migrações
```

### **Testar**
```bash
# Testes organizados
cd testing/
python test_appointments_api.py

# Testes E2E
./utilities/run-critical-e2e-tests.sh
```

### **Documentar**
```bash
# Consultar relatórios
ls documentation/reports/
cat documentation/next-steps.md

# Ver estrutura
cat PROJECT_STRUCTURE.md
```

### **Utilitários**
```bash
# Scripts úteis
cd utilities/
./run-critical-e2e-tests.sh
python analyze_schema_inconsistencies.py
```
